# Typink AI Context

## Project Overview
**Typink** is a simple, modern desktop application that automatically types user-provided text at the current cursor position. It is built using Python, `customtkinter` for the GUI, and `pyautogui` for keyboard simulation.

## Tech Stack
- **Language**: Python 3.x
- **GUI Framework**: CustomTkinter (`customtkinter`)
- **Automation**: PyAutoGUI (`pyautogui`)
- **Executable Builder**: PyInstaller (configured via `Typink.spec` and standard CLI arguments)

## File Structure
- `main.py`: The core application file containing all the logic and UI code.
- `README.md`: Project documentation.
- `Typink.spec`: PyInstaller spec file for building the executable.
- `assets/`: Contains image assets (e.g., logo).
- `dist/` & `build/`: Directories generated by PyInstaller containing the compiled executable.

## Architecture & Implementation Details
- **Main App Class**: `TypinkApp(ctk.CTk)` handles the main UI window layout, including a text box, typing speed slider, progress bar, and control buttons (Start, Pause, Stop, Float).
- **Typing Logic**: Handled in a separate background thread (`typing_process`) to prevent blocking the main UI loop. Uses `pyautogui.write()` to simulate keystrokes.
- **Speed Control**: Uses a configurable delay between keystrokes (1ms to 1000ms). The `pyautogui.PAUSE` is globally set to 0.01.
- **Pause/Resume**: Includes a 5-second countdown to allow the user to focus the target application before typing begins or resumes.
- **Floating Window**: `toggle_float()` creates a `ctk.CTkToplevel` window that is configured to be always-on-top (`attributes('-topmost', True)`). It includes Start, Pause, Stop controls and an adjustable transparency slider.
- **Safety**: `pyautogui.FAILSAFE = True` is enabled.

## Key Features for Agents to Know
1. **Threaded Typing**: Typing must remain on a background thread so the GUI remains responsive.
2. **Countdown Mechanism**: Essential feature to give users time to click into the target input field.
3. **State Management**: Booleans `is_typing` and `is_paused` control the execution flow within the typing loop.
